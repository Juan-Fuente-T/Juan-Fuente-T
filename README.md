### 👨‍💻 Sobre mí: Mentalidad Artesana aplicada al Software

Vengo de un sector exigente donde el error no es una opción. Tras años en la artesanía de precisión y con un material crítico como el vidrio, traslado esa **disciplina, paciencia y atención al detalle** al código.

Además de precisión y profunda capacidad analítica aporto madurez, compromiso, enorme ética profesional, autonomía, proactividad, gran adaptabilidad y una curva de aprendizaje acelerada.
* **Enfoque:** Busco la robustez. Prefiero entender el "por qué" falla algo antes que copiar una solución rápida.
* **Técnica:** Especializado en el ecosistema Java (Spring Boot) y Frontends modernos (React/Javascript-Typecript). Tengo conocimientos también en Angular o Node.js.
* **Calidad:** Me esfuerzo por entregar código limpio, documentado y probado (Unit & Integration Testing), evitando deuda técnica futura.
